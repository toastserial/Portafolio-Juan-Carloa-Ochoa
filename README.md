# Portfolio Testing

Base aislada para la nueva versión del portafolio personal.

## Scripts

- `npm run dev`: inicia el entorno de desarrollo.
- `npm run build`: valida TypeScript y crea el build de producción.
- `npm run lint`: ejecuta ESLint.
- `npm run preview`: sirve el build localmente.
- `npm run typecheck`: valida los tipos sin emitir archivos.

## Estado

La implementación incluye contenido bilingüe, layout editorial, datos
centralizados, navegación responsive, assets personales y una escena 3D
progresiva. En móvil se utiliza una imagen estática; en escritorio el modelo se
carga al aproximarse al viewport y se pausa cuando la pestaña no está visible.

Los proyectos heredados del portafolio anterior se presentan como conceptos o
prácticas técnicas, sin enlaces ni resultados no verificables.
